PLURA-WAF Concept

웹방화벽은 이제
차단 장비가 아니라
공격 증거를 해석하는 플랫폼이어야 합니다.

PLURA-WAF는 단순한 시그니처 매칭을 넘어, 실제 웹 요청과 응답 본문을 보안 판단의 근거로 사용합니다. 공격이 웹에서 시작되면 서버 내부 행위, 계정 이벤트, 파일 변경까지 이어서 분석해야 합니다.

  • 원본 웹 요청/응답 본문 기반의 상세 로그 확보
  • AI 기반 제로데이·우회형 페이로드 탐지
  • 탐지 결과에 따른 정책 기반 자동 차단
  • EDR·SIEM과 연계한 웹셸, RCE, 계정 탈취 후속 행위 추적

웹 요청 수집

URL, Header, Query, Body, Response까지 공격 판단에 필요한 원본 근거를 확보합니다.

AI 위협 분석

알려진 패턴뿐 아니라 인코딩, 난독화, 컨텍스트 탈출, 비정상 로그인 흐름을 함께 판단합니다.

정책 기반 차단

고위험 공격은 즉시 차단하고, 검토가 필요한 이벤트는 관제·분석 흐름으로 연결합니다.

XDR 상관분석

웹 공격 이후의 프로세스 실행, 파일 생성, 계정 로그인, 데이터 반출 징후를 연결합니다.

핵심: 웹에서 막고, 서버에서 확인하며, 로그로 증명합니다. 이것이 PLURA-WAF 기반 xWAF의 차별점입니다.

PLURA-WAF 주요 방어 기능

DDoS·봇 공격 대응

클라우드 기반 엣지 보호와 트래픽 분석으로
대규모 요청 폭주와 자동화 봇 접근을 식별하고
서비스 가용성을 보호합니다.

웹셸·RCE 탐지

업로드, 명령 실행, 의심 스크립트 호출 등
웹셸과 원격 명령 실행 징후를 실시간 탐지합니다.

EDR 연동으로 프로세스 실행, 파일 생성, 권한 변경까지 추적해 웹 공격 이후의 후속 행위를 확인합니다.

제로데이·우회 공격 대응

원본 요청/응답 본문과 로그를 함께 분석하여
신규 취약점 악용, 인코딩·난독화, 시그니처 우회형 페이로드를 조기에 탐지합니다.

AI 분석 결과와 정책을 결합해 고위험 공격은 자동 차단하고 분석 근거를 남깁니다.

크리덴셜 스터핑 방어

대량 로그인 시도, 실패율 급증, 계정 순회, IP 분산 접근 등 계정 탈취 흐름을 실시간 분석합니다.

IP·계정·세션·User-Agent 기준의 이상행위 탐지와 정책 기반 차단을 함께 제공합니다.

데이터 유출 방지

응답 본문, 다운로드 패턴, 민감 정보 노출 징후를 분석해 개인정보·기밀 정보 유출 시도를 탐지합니다.

비정상 대량 조회, 디렉터리 노출, 오류·디버그 정보 노출까지 함께 모니터링합니다.

MITRE ATT&CK 연계

웹 공격을 단일 이벤트로 끝내지 않고
초기 침투, 실행, 지속성, 권한 상승, 데이터 반출 단계로 확장해 분석합니다.
